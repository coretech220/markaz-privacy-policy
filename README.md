# Markaz Privacy Policy

Public, bilingual privacy-policy website for Markaz — Sayyid Shouhadaa Center
(مركز سيد الشهداء ع).

- Arabic policy: `index.html`
- English policy: `en/index.html`
- Self-hosted styling: `styles.css`
- Public application icon: `assets/icon.png`
- `.nojekyll` enables plain static hosting on GitHub Pages.

The site contains no application source code, credentials, analytics scripts,
remote fonts, forms or JavaScript. Both languages remain readable without script
execution. Policies describe the current Android functionality; a future iOS
implementation requires its own functionality and SDK review before release.

Effective date: 17 November 2026. Privacy contact:
info@sayyid-shouhadaa-center.com.

To host through GitHub Pages, select **Deploy from a branch**, branch **main**,
folder **/(root)**. The intended public address is:
https://coretech220.github.io/markaz-privacy-policy/

Repository preparation alone does not establish that the site is published.
Verify the actual HTTPS pages after deployment before using them in the app or
store listing.
